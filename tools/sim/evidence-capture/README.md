# Manual capture addon (research only)
Copy this folder as OctoSimCapture into Interface/AddOns. Log in, remove gear and buffs voluntarily, choose a neutral talent setup, then run /octocapture. Log out to flush WTF/Account/.../SavedVariables/OctoSimCapture.lua. Review the file before sharing. It contains realm/build, attributes, equipment links, auras and spellbook names/ranks; not character names. The stock 1.12 spellbook index is NOT a spell ID. Max health/mana is NOT innate base health/mana. The collector does not assert that a character is clean or that any fields represent true server base values. Lua syntax and game-client behaviour need live testing.

Convert reviewed observations into the JSON schema accepted by tools/sim/review-base-evidence.mjs only after independently establishing all seven innate values and the extraction method. The reviewer rejects contaminated/incomplete rows, separates realm/phase/client build, retains disagreements and requires distinct observer/capture/raw evidence references for corroboration. Those references must be manually authenticated; this is not automatic proof. Do not upload unrelated SavedVariables.

Public research found community level-60 racial offsets in RelationshipsDashboard (https://octowow.st/git/Relationship/RelationshipsDashboard/src/commit/96fc4647d859ed19d8d565ed20c80aa6b00fb474/RelationshipsDashboard.lua), explicitly rough estimates, not a server level-stat table. AdeTalents (https://octowow.st/git/Ade/AdeTalents) provides in-client talent dumps but excludes spell costs/cooldowns. Neither can establish the missing 1,140 seven-field base rows or resolve all spell conflicts. No guesses imported.
