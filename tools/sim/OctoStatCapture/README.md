# Anonymous base-stat capture (experimental)
Copy this folder to Interface/AddOns/OctoStatCapture and enable it in the 1.12 client. On an unmodified OctoWoW character, unequip all gear, remove all visible auras, spend no talent points, remain alive and out of combat, and leave druid forms. Run /octostat. Log out or /reload to write the saved variables.
Only race, class, level, five UnitStat tuples, maximum health and current resource pool/type are recorded. Do not submit the whole WTF directory or account names. Copy only OCTOSTAT1 lines from the addon's SavedVariables/OctoStatCapture.lua file into an anonymous text file.
Run from the repository root: node tools/sim/review-base-stat-captures.mjs capture.txt
The review report flags conflicting observations and compares existing imported reference attributes. It does not modify the planner or promote a capture as verified. Raw class health/mana must be established separately; maximum HP/mana are not those columns. Racial/passive, hidden aura, build version, and client API semantics must be reviewed manually. Record server patch and realm separately if useful, without identifying characters. This initial addon has not been run in-game.
