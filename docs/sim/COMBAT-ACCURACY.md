# Phase 2 — Shared combat accuracy
Calculated incoming attacks are opt-in via incomingDamage[].attackModel in explicit class encounters. Existing amount-only events retain their post-table semantics. Physical models specify a complete attack table and attacker-level armour formula (Classic reference now covers raid enemies through level 63). Spell models specify binary/nonbinary/none conditional resistance and critical distribution. Results retain rolled outcomes, partial resistance and critical flags before shields and class-specific damage multipliers. A calculated attack cannot be combined with the older blockModel or resolved amount/outcome; dynamic Shield Block/Redoubt probability changes still use the older path and are not silently added to calculated tables. No OctoWoW-specific resistance distribution is inferred from rating. Reference formula validation is not live verification.

## Resource regeneration
An optional fiveSecondRule policy on a mana regeneration event accepts explicit windowMs and insideAmount; the ordinary amount is the outside rate. Paid action and channel tick costs record actual spend time; failed or free actions do not restart the window. Existing explicit regeneration remains unchanged. This models action expenditure only; non-action scripted drains are not assumed to restart the window. Server-specific spirit coefficients, MP5 decomposition and timing remain external evidence requirements.
